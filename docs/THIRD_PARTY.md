# Third-party components

Capacitor dependencies are declared in `package.json` and pinned in `package-lock.json`. Android dependencies are declared in the Gradle files. Their licenses continue to apply; no third-party ownership is claimed.

The checked-in Gradle launcher scripts preserve their original Apache 2.0 notices. The Gradle wrapper JAR and Android launcher/splash resources are retained from the existing project as build inputs. The launcher resources are not screenshots of gameplay.

The game draws its city map and interface in SVG/CSS and uses system-rendered emoji for some visual elements. Emoji appearance varies by device.

No new permissive license has been selected for the original application. Review licensing before redistributing the project or creating a store release.
